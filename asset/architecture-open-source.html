Skardi · Open Source Architecture

An agent data plane that gives AI agents data autonomy.

Any AI agent — Claude Code, Codex, your own — talks to skardi-server through a uniform set of skills (rag, grep, batch, ingest) and gets governed access to every database, file, and object store you connect. One control plane. Any source. Federated SQL + retrieval primitives, written in Rust.
